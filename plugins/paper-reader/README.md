# 论文阅读器

在 Codex 聊天旁阅读原始论文 PDF，选段解释、翻译与追问留在当前聊天。使用当前聊天的模型，无需额外模型 API。

## 使用

按[仓库安装说明](../../README.md#安装)安装 `paper-reader` 后，在聊天中说「打开论文阅读器」。支持内容标签页入口的客户端，可点击当前聊天右上角「＋」，选择「论文阅读器」。

搜索本机 Zotero 的标题或作者，点击论文直接打开 PDF。选择论文不会自动发消息或新建聊天。阅读器支持收藏夹筛选、连续阅读、跳页、缩放、文字选择和「问这一页」。选段问题携带论文标题和原始 PDF 页码；调整缩放或切换论文会清除选段。

本地 PDF 可以通过界面中的文件选择打开。它在浏览器中解析，选段问答可使用提取文字；模型需要查看本地 PDF 的图表时，请在聊天附上 PDF 或页面截图。扫描件没有文字层时无法拖选文字；Zotero 中的扫描件可以通过页面图像工具核对。

## 跟随主题

默认「跟随 Codex」，工具栏、阅读背景、PDF 纸张与文字同步宿主明暗主题。与皮肤工作室组合使用时，也跟随自定义配色、渐变、壁纸、透明度和模糊。

右上角「原色纸张」可恢复原始显示颜色，选择会记住。显示滤镜不修改 PDF 文件；图表颜色会随滤镜变化，核对图表原色时应切回原色。模型读取页面图像始终使用原始 PDF。

## 环境

- Python 3.11+，通过 `python3` 启动；后端只使用标准库。
- Zotero Desktop 的本地 API 位于 `http://127.0.0.1:23119/api/users/0`。需在 Zotero 的配置编辑器中启用 `extensions.zotero.httpServer.localAPI.enabled`，并保持 Zotero 运行。
- 可选 Poppler：`pdftotext` 提取指定页文字，`pdftoppm` 返回指定页图像，`pdfinfo` 统计页数。缺少时工具会报告；界面显示 PDF 使用随包提供的 PDF.js。
- 本地 PDF 阅读不依赖 Zotero。

PDF 字节仅按需进入界面元数据，不会自动作为模型文本。点击选段问答时，所选原文、标题、页码进入当前聊天。模型需要更多证据时，可使用 `read_paper_page` 读取指定页。

## 本地预览

在此插件目录中运行：

```sh
python3 server.py --http 8768
```

打开 `http://127.0.0.1:8768`。预览服务仅监听回环地址；快捷问答按钮复制带原文和页码的问题。Codex 原生 MCP Apps 面板中的按钮使用宿主消息接口发送到当前聊天。

## 验证范围

macOS Codex 原生 MCP Apps 面板已验证 PDF 渲染、页码导航、自定义紫色主题与背景透明度同步；明暗切换和原色显示另经模拟宿主验证。聊天消息桥接经模拟宿主验证，真实模型回复未作为测试项执行。后端检查覆盖 PDF 字节隔离、读取边界、非法页码和 stdio 协议。
